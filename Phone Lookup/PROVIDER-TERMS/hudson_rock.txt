HUDSON ROCK (Cavalier free OSINT endpoint)

Sends the subject's phone number in E.164 form (including the leading +) as the `username` query parameter to cavalier.hudsonrock.com (providers/hudson.py:9,13). No API key is used. The code comment in providers/hudson.py states that Hudson Rock may log the query. Retention, logging and permitted-use terms: see vendor. You must be authorized to query this subject, and you remain responsible for each query you send. The operator is responsible for holding their own relationship with the vendor and for accepting the vendor's terms of service; this repository does not do so on your behalf.

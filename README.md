# OSINT Toolkit

> People-focused OSINT. Authorized, lawful use only — see [LEGAL-USE.md](LEGAL-USE.md).

Hardened, local Docker launchers for common people-focused OSINT tools, plus a case workbench that ties their output together. It is built for authorized investigators who want scans to run in isolated containers, behind a network gate, with an accountability record for every subject.

**Platform:** Windows only for v1 (Docker Desktop and PowerShell 7). POSIX launchers are on the roadmap.

## Three gates before anything runs

1. **Network gate.** Every scan checks that traffic leaves through your VPN or proxy route; a refused run exits 75.
2. **Typed RUN.** Collection starts only after you type `RUN`; menu navigation alone cannot start a scan.
3. **Subject authorization and provider terms.** A case needs a recorded authorization attestation (exit 77 otherwise), and optional third-party providers need their own typed terms acceptance.

The attestation is an accountability record, not a security boundary. Permitted use is defined in [LEGAL-USE.md](LEGAL-USE.md).

## Quick start

Prerequisites: Docker Desktop (running), PowerShell 7, Python 3.11+, git.

```powershell
git clone <this repository>
Set-Location <repo>

# For each tool you want (Maigret Docker, TorBot Docker, User-Scanner Docker, Phone Lookup):
python -I shared/build/fetch_wheelhouse.py --tool "Maigret Docker"
Set-Location '.\Maigret Docker'; docker compose build; Set-Location ..
```

`<repo>` is your clone directory. Images and wheelhouses are never published; you build them locally from the hash-pinned locks (see each tool's "Build from a clean clone" section where present).

Then install the case workbench and run a first scan:

```powershell
& '.\OSINT Profiler\install.ps1'
# open a new PowerShell terminal so the updated PATH applies
osint-case new demo --question "Which accounts belong together?"
osint-case authorize demo
osint-case scan demo          # choose a tool from the menu; type RUN to start
```

Each tool also installs a one-word launcher (`user-scanner`, `maigret`, `torbot`, `phone-lookup`) via its `install-launcher.ps1`.

## Data location

Case data and reports live outside the repository, in a data root resolved as `--root`, then the `OSINT_ROOT` environment variable, then `%LOCALAPPDATA%\OsintToolkit\data` (see the [Data location](./OSINT%20Profiler/README.md#data-location) section of the profiler guide). Nothing is moved automatically: if you have older cases under `OSINT/` (gitignored and never synced; see [`OSINT/README.md`](./OSINT/README.md)), copy them across with `osint-case migrate-root`. Do not commit or sync case data.

This repository publishes **source and hash-pinned lock files only**. No container images and no wheelhouses are published; each operator builds the images locally from the locks.

- **TorBot is GPL-3.0.** It runs only inside its own image and its own compose project (`TorBot Docker/`), and shares no code with the Apache-2.0 tools. Nothing here links TorBot into another tool.
- LGPL dependencies (for example `yattag` and `pycountry`) are installed as unmodified, replaceable wheels pinned by hash in the tool's lock.
